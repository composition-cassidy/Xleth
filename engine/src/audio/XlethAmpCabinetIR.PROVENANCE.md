# Amp Stack cabinet IR provenance

**Status: PLACEHOLDER. Nothing in this directory is a recording. Do not ship a
release that still depends on it without reading section 3 below.**

Applies to: `engine/src/audio/XlethAmpCabinetIR.h`
Spec: `docs/amp spec.docx` §6 (Cabinet IR set), §9 (Engine constraints),
§10.5 (IR licensing acceptance test).

## 1. What is actually in the build right now

There are **no impulse response files** in this repository. The four cabinets
the Amp Stack effect offers are **synthesised procedurally at runtime** by
`xleth::audio::amp::synthesizePlaceholderCabinetIR()` in
`XlethAmpCabinetIR.h`.

Each one is a designed FIR:

* a unit impulse plus three signed early reflections (a stand-in for baffle and
  back-wall bounce),
* a cascade of six biquads — high-pass, resonance peak, body peak/scoop, mid
  peak, low-pass, high shelf — whose corner frequencies were chosen to match the
  *character note* the spec gives for that cabinet,
* an exponential decay envelope with a raised-cosine fade-out,
* peak-magnitude normalisation to `max|H(f)| == 1.0`.

The biquads are designed at the **measured engine sample rate**, so the IR is
generated at that rate. There is no 44.1-vs-48 kHz assumption anywhere in the
file and no load-time resampling error.

| Cabinet | Spec §6 character note | What the placeholder curve does |
|---|---|---|
| Open-back 1×12 | "Round, open, less mid focus" | HP 105 Hz, resonance 95 Hz +3.5 dB, 480 Hz −2.5 dB scoop, LP 6.0 kHz |
| Alnico 2×12 | "Warm, vintage compression feel" | HP 82 Hz, resonance 88 Hz +4.0 dB, 700 Hz +2.5 dB body, LP 5.5 kHz |
| Greenback 4×12 | "Smooth top roll-off ≈5 kHz" | HP 76 Hz, resonance 80 Hz +4.5 dB, 1.7 kHz +2.5 dB, **LP 5.0 kHz** |
| V30 4×12 | "Mid spike ≈3 kHz, extended top" | HP 74 Hz, resonance 78 Hz +4.5 dB, 520 Hz −3.5 dB scoop, **3.0 kHz +5.0 dB spike**, LP 6.8 kHz |

All four are between 28 ms and 34 ms long — comfortably inside the spec's
≤ 100 ms ceiling, which `kMaxCabinetIrMs` enforces in code.

`engine/test/test_amp.cpp` asserts the two figures the spec states numerically:
the Greenback's ≈5 kHz roll-off and the V30's ≈3 kHz mid spike.

## 2. Licensing status of the placeholders

**Clean.** The placeholder IRs are generated by XLETH's own code from
filter-design mathematics. No sample, no recording, no commercial IR pack, and
no third-party dataset was used, consulted, or reverse-engineered to produce
them. They are original work in this repository and carry the repository's
licence.

Being clean is not the same as being finished. See below.

## 3. What still has to happen before release

Spec §10.5 requires that *every shipped IR is CC0 or self-recorded, provenance
on file*. Synthesised placeholders satisfy the licensing half of that test
trivially, but they do **not** satisfy the intent: they are not measurements of
speakers, and the spec's §10.6 tuning pass ("all six models get a listening pass
on real pre-cleaned pitch samples") cannot be signed off against them.

Before Amp Stack ships:

1. Replace each of the four with either
   * a **self-recorded** IR (XLETH's own cab + mic + interface, with the mic
     position, speaker, cab, and preamp recorded in this file), or
   * a **CC0** IR from a source whose CC0 dedication is verifiable — record the
     source URL, the author, the licence text location, and the download date
     in this file.
2. Keep the ≤ 100 ms ceiling. Trim and fade the recording; do not ship a
   reverberant room tail inside a cab IR.
3. Load them through the same `loadImpulseResponse(buffer, irSampleRate, ...)`
   call the placeholders use. Passing the file's own native rate lets
   `juce::dsp::Convolution` do the resample to the engine rate — that is the one
   place resampling is allowed to happen, and it is JUCE's, not ours.
4. Re-run `test_amp` and update the two character assertions to the measured
   figures of the real IRs.
5. Delete the PLACEHOLDER banner from `XlethAmpCabinetIR.h` and rewrite section
   1 of this file to describe the recordings.

Until step 5 is done, the banner stays and this file is the reason.
