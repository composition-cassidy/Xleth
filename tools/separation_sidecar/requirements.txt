# --- NVIDIA / CUDA (fastest: ~0.05x realtime, measured on an RTX 4080) -------
# onnxruntime-gpu==1.24.4
# nvidia-cudnn-cu12
# nvidia-cublas-cu12
#
# READ THIS BEFORE PICKING A VERSION. Each onnxruntime-gpu release targets one
# CUDA major, and getting it wrong costs an hour:
#
#   onnxruntime-gpu 1.24.x  ->  CUDA 12 + cuDNN 9   <- use this one
#   onnxruntime-gpu 1.29.x  ->  CUDA 13 + cuDNN 9
#
# 1.29 is the newest and pip installs it by default, but there are NO Windows
# wheels for the CUDA 13 runtime — nvidia-cublas-cu13 and
# nvidia-cuda-runtime-cu13 are 0.0.1 placeholder sdists on PyPI and on
# pypi.nvidia.com alike, and no cp314 torch cu130 wheel exists either. So on
# Windows, pin 1.24.4 and use the cu12 packages. Hence the == above, not >=.
#
# A system CUDA Toolkit install does NOT make this work on its own: it ships
# cuBLAS but not cuDNN. The pip packages above supply cuDNN, and mdx.py's
# _register_cuda_dll_dirs() both registers their directories AND ctypes-loads
# the DLLs — os.add_dll_directory alone is not enough, because onnxruntime
# loads its provider DLL through a plain LoadLibrary that does not consult
# user-added directories. Without that preload you get
# "cudnn64_9.dll ... missing (Error 126)" and a SILENT fallback to CPU.
#
# --- DirectML (any DX12 GPU, no CUDA deps at all) ----------------------------
# onnxruntime-directml
#
# Slower than CUDA on an NVIDIA card, but immune to every version trap above.

# ── GPU for the BALANCED tier is a SEPARATE question from the FAST tier ─────
#
# The Roformer tiers infer in torch. A CUDA onnxruntime does nothing for them.
# The default `torch` wheel on Windows is CPU-only, so on a stock install of
# this file the FAST tier runs on the GPU and BALANCED runs on the CPU at
# roughly 3.1x realtime — a three-minute song in ten minutes.
#
# That is not a bug and the sidecar reports it honestly (per-architecture
# device in /health and /models, and the device chip in the separation strip).
# To move BALANCED onto the GPU as well, install a CUDA torch build:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cu126
#
# Check it took, rather than assuming — the failure is silent:
#
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
